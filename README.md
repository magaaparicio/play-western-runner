# Western Runner 🤠

Un videojuego arcade 2D inspirado en el Viejo Oeste.

Un vaquero, su caballo y una carrera infinita por el desierto. Salta obstáculos, recoge cartas de póker y atrapa sombreros para multiplicar tus puntos.

**¿Hasta dónde puedes llegar?**
