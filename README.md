# Western Runner

**Un videojuego arcade 2D desarrollado con inteligencia artificial.**

Western Runner es un juego interactivo inspirado en el Viejo Oeste, donde un vaquero a caballo debe esquivar obstáculos, recolectar cartas y conseguir la mayor puntuación posible.

El proyecto explora cómo la inteligencia artificial puede utilizarse para diseñar, desarrollar y lanzar experiencias digitales interactivas sin recurrir a motores de videojuegos tradicionales.

## Cómo jugar

- **60 segundos:** consigue tantos puntos como puedas antes de que termine el tiempo.
- **Modo sin fin:** sobrevive el mayor tiempo posible.
- **Reto del día:** compite por superar tu mejor puntuación diaria.
- **Cartas de póker:** suma puntos recolectándolas.
- **Sombreros:** duplica temporalmente tus puntos.
- **Obstáculos:** esquiva barriles, cercas, rocas y otros elementos del camino.

Compatible con dispositivos móviles y computadoras.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- Canvas API
- Web Audio API
- Claude AI — apoyo en desarrollo y programación

El juego funciona directamente en el navegador, sin instalaciones ni frameworks.

## Sobre el proyecto

Western Runner nació como un experimento para explorar la creación de experiencias interactivas mediante IA.

Más allá del videojuego, el objetivo es experimentar con formatos que puedan aplicarse al entretenimiento digital, la gamificación y las experiencias de marca.
